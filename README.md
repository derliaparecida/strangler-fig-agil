# strangler-fig-agil

### Tema: Um guia pratico para a evolução de sistemas com Strangler Fig usando métodos ágeis.




### Objetivo principal:
Mostrar, de forma simples, direta e organizada, como modernizar sistemas antigos sem grandes riscos, substituindo partes do sistema de forma gradual e controlada.

O material explicará as principais etapas do processo - análise, divisão, construção, migração e desativação — alinhadas com práticas ágeis.

Serão incluídos exemplos práticos de código para demonstrar a aplicação da técnica, utilizando trechos de projetos abandonados no GitHub ou partes de código real adaptado para ilustrar o processo.



### Estrutura:

- conceito de strangler fig no contexto de sistemas legados
- passo a passo prático da abordagem usando scrum
- como planejar a divisão do sistema legado em partes menores
- como organizar um backlog técnico 
- exemplo de aplicação prática da abordagem
